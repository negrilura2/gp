# 毕业设计说明书大纲
论文题目：基于声纹识别的智能门禁系统的设计与实现

## 第1章 绪论
### 1.1 选题背景与意义
- 1.1.1 传统门禁系统的局限性与生物特征识别技术的发展。
- 1.1.2 声纹识别在非接触身份认证场景中的应用优势。
- 1.1.3 智能家居与自然语音交互的发展趋势。
- 1.1.4 本课题的研究意义：构建兼顾识别能力、交互能力与工程可实现性的智能门禁原型系统。

### 1.2 国内外研究现状
- 1.2.1 声纹识别技术发展脉络：GMM-UBM、i-vector、x-vector 到 ECAPA-TDNN。
- 1.2.2 实时语音交互系统研究现状：流式识别、VAD、WebSocket 音频传输。
- 1.2.3 智能门禁系统研究现状：单一认证系统向多模块协同系统演进。
- 1.2.4 语音伪造攻击与防御研究现状，可作为安全扩展方向讨论。

### 1.3 本文主要研究内容
- 1.3.1 构建基于 ECAPA-TDNN 的声纹识别模型，实现注册、检索与验证流程。
- 1.3.2 设计 Django + FastAPI + Vue 3 的前后端分离系统架构。
- 1.3.3 实现基于 WebSocket 的实时音频流处理机制，结合 VAD、STT 与 TTS 完成交互闭环。
- 1.3.4 设计“本地规则 + 云端 Agent”的混合智能处理流程，实现高频命令与复杂问答的分流。
- 1.3.5 构建管理员后台，实现日志审计、阈值调整、模型切换和评估展示。

### 1.4 论文组织结构
- 说明各章节内容安排及逻辑关系。

## 第2章 相关技术研究
### 2.1 声纹识别相关技术
- 2.1.1 语音信号预处理：预加重、分帧、加窗与归一化。
- 2.1.2 特征提取方法：MFCC 及其差分特征，必要时补充 LogMel 对比。
- 2.1.3 ECAPA-TDNN 模型结构与优势分析。
- 2.1.4 AAM-Softmax 等度量学习损失函数原理。

### 2.2 向量检索与数据存储技术
- 2.2.1 声纹向量表示与相似度计算方法。
- 2.2.2 ChromaDB 在声纹向量存储与检索中的应用。
- 2.2.3 ChromaDB 在本地知识库中的应用。
- 2.2.4 MySQL 或 SQLite 在用户、日志和系统配置管理中的作用。

### 2.3 系统工程与智能交互技术
- 2.3.1 Django REST Framework 在业务接口层中的应用。
- 2.3.2 FastAPI 在 AI 服务拆分中的应用。
- 2.3.3 Vue 3 在前端交互与管理界面中的应用。
- 2.3.4 WebSocket、VAD 与流式语音交互机制。
- 2.3.5 大语言模型与 Agent 技术在复杂语义理解中的应用。

## 第3章 系统需求分析
### 3.1 业务流程分析
- 3.1.1 用户注册与声纹录入流程。
- 3.1.2 用户声纹验证与门禁判定流程。
- 3.1.3 实时语音交互与智能响应流程。
- 3.1.4 管理员后台审计与运维流程。

### 3.2 功能需求分析
- 3.2.1 用户端功能需求：
  - 声纹注册与验证。
  - 实时录音、波形展示与流式交互。
  - 基于身份识别结果的语音响应与问答。
- 3.2.2 管理端功能需求：
  - 用户与管理员账号管理。
  - 访问日志、注册日志、管理员操作日志查询。
  - 模型切换、阈值调整、评估结果查看。
- 3.2.3 AI 服务功能需求：
  - 声纹特征提取与向量检索。
  - 语音转写与文本转语音。
  - 本地 NLU 与云端 Agent 的协同决策。

### 3.3 非功能需求分析
- 3.3.1 实时性需求：系统交互需具备较低延迟。
- 3.3.2 准确性需求：声纹识别准确率与 EER 指标满足实验要求。
- 3.3.3 安全性需求：鉴权、日志记录、异常访问提示与基础防护策略。
- 3.3.4 可维护性需求：模块解耦、接口清晰、前后端分离。

## 第4章 系统设计
### 4.1 系统总体架构设计
- 4.1.1 系统采用前端、业务后端、AI 服务三层解耦结构。
- 4.1.2 前端负责页面交互与音频采集，Django 负责业务管理，FastAPI 负责 AI 推理。
- 4.1.3 系统同时包含运行态链路与实验态链路。

### 4.2 核心业务流程设计
- 4.2.1 HTTP 声纹注册与验证流程设计。
- 4.2.2 WebSocket 实时语音交互流程设计。
- 4.2.3 本地 NLU 与云端 Agent 的混合智能决策流程设计。

### 4.3 核心模块设计
- 4.3.1 音频流处理模块：缓冲区、VAD 触发与语音片段切分。
- 4.3.2 声纹识别模块：模型加载、特征提取、向量检索与阈值判决。
- 4.3.3 智能交互模块：STT、知识库检索、Agent 推理与 TTS 回传。
- 4.3.4 后台管理模块：用户管理、日志审计、模型与阈值管理。

### 4.4 数据与接口设计
- 4.4.1 关系型数据模型设计：User、UserProfile、VerifyLog、EnrollLog、AdminAccessLog。
- 4.4.2 向量集合设计：voiceprints 与知识库集合。
- 4.4.3 RESTful API 设计：注册、登录、验证、日志、统计、评估。
- 4.4.4 WebSocket 消息设计：结果开始、文本流、音频流、完成信令等。
